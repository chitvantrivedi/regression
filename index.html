What regression is actually doing

Every possible curve leaves a gap (a residual) between each point and the curve. Regression picks the one whose squared gaps add up to the smallest total. Choose a model, move it yourself, then watch the computer find it.

1. Try to beat the best curve

Orange segments are residuals. Orange squares have an area equal to each squared residual, so total orange area is the quantity being minimized. Coefficients use u = (x − 5) / 5, which keeps the numbers well behaved for higher degrees.

2. The error landscape

Every combination of coefficients is a point on this map, shaded by its SSE. Brighter means lower error, and there is a single valley bottom, so exactly one best curve exists. The map shows the two highest-order coefficients; all others are held at their best values. Click to put the curve there (the other coefficients jump to their best values too).

4. Build the curve one point at a time

Points arrive in the order they were collected. After each arrival, the curve is recomputed from every point so far. Previous curves fade behind the new one, and the grey dashed curve is where it is heading. A curve with d + 1 coefficients needs at least d + 1 points, and with exactly that many it passes through all of them.

5. What a residual plot is plotting

A residual is the vertical gap between a point and the fitted curve: residual = y − fitted y. A residual plot subtracts the curve from every point, which flattens it to zero and leaves only the gaps. Press the button to watch it happen, and click any dot to see its numbers. Try Curved data with the Linear model, then switch to Quadratic.
